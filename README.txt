HOW TO RUN:

1. Open the frontend folder in VS Code.
2. Install Live Server extension.
3. Open index.html.
4. Right-click and select Open with Live Server.

BACKEND CONNECTION:

API URL:
http://localhost:8080/api/scams/analyze

Backend must be running for actual AI scan results.

NOTE:
Scan history is currently stored in browser localStorage.
Actual AI detection requires backend and AI API integration.
